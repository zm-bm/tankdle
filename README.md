# Tankdle

## About

Tankdle is a daily tank-identification game inspired by Wordle. Guess the tank
from its image, using the details revealed by each guess to narrow down the
answer.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` to create a production build and `npm run lint` to check the
code.
